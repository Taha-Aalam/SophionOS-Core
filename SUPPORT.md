# Support

## How to get help

| Need | Where |
|------|--------|
| Setup / self-hosting / docs questions | GitHub **Discussions** (preferred) or a docs PR |
| Reproducible product bug | GitHub **Issues** (bug template) |
| Feature idea | GitHub **Discussions** first; then an issue if maintainers agree |
| Security vulnerability | Private path in **`SECURITY.md` only** — never public issues |
| Sophion **Cloud** account, billing, or managed hosting | Official Cloud support (not this OSS tracker) |

## Before opening an issue

1. Search existing issues and Discussions.
2. Read `docs/known-limitations.md` and `docs/self-hosting.md`.
3. Include version/commit, OS, Node/pnpm versions, and reproduction steps.

## What we cannot provide via GitHub Issues

- Custom consulting for your deployment
- Guaranteed SLA for alpha builds
- Debugging your production secrets or dumping customer data
- Support for unofficial forks claiming official status

## Community expectations

See `CODE_OF_CONDUCT.md`. Be specific, kind, and patient — this is a volunteer
maintained open-source alpha.
