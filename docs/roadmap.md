# Public roadmap

High-level intent only. Not a commitment or schedule.

- Harden open-source self-host path and documentation
- Keep export/deletion and key revocation trustworthy
- Expand automated tests for authz and RLS where environment allows
- Clarify experimental API/MCP until scopes and defaults are complete

## Medium term (developer beta)

- Stable API versioning and OpenAPI
- MCP read-only defaults and scope model
- Improved Docker/deployment story
- Richer demo templates

## Later

- Auth alternatives (if demand warrants)
- Formal security review summary
- Sophion Cloud managed experience (commercial)
- SophionOS Business / governance features (commercial)
