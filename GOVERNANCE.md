# Governance

## Early-stage model

SophionOS is in **public alpha**. The founding maintainer(s) retain final
decision-making authority on product direction, security, licensing, and
releases.

## Decision criteria

Changes are evaluated for:

1. Security and privacy impact (especially RLS, API keys, MCP)
2. Maintainability and testability
3. Alignment with personal connected-context product goals
4. Community impact and contributor experience
5. Clear separation from Sophion Cloud / Business commercial offerings

## How to propose changes

- Small fixes: open a pull request (see `CONTRIBUTING.md`). All pull requests
  require a signed Contributor License Agreement (`CLA.md`) before merge.
- Large features or architectural changes: open a Discussion first
- Security-sensitive work: follow `SECURITY.md` if disclosure is needed

## Maintainers

Additional maintainers may be invited based on sustained high-quality
contributions, review reliability, and security judgment. Process will be
documented when the project grows beyond a single maintainer.

## Releases

- Semantic versioning for tagged releases (`v0.x` while alpha/beta)
- Release notes via `CHANGELOG.md` and GitHub Releases

## Roadmap

Public direction is summarized in `README.md` and `CHANGELOG.md`. Planning notes
are not binding commitments.
